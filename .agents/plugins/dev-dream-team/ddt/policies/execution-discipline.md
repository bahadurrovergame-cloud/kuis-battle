# Execution Discipline

Before an exploratory command, test, or mutation, state briefly:

- objective;
- confirmed and unknown facts;
- causal hypothesis and predicted observation;
- cheapest discriminating action;
- bounded observation/action plan and stop condition.

A materially different hypothesis needs a different causal explanation, a different prediction, and evidence that distinguishes it. Parameter changes and repeated samples for the same explanation remain one hypothesis.

After a result, record only the useful evidence: confirmed, eliminated, current hypothesis, open unknowns, and next discriminating action. Do not repeat equivalent searches, commands, or tests without new evidence.

An unreliable test harness, setup failure, or external outage is classified before it can count as a failed product hypothesis. Reassess when the observation plan is exhausted, prediction is contradicted, output stops adding information, or context/action budget is exhausted.
